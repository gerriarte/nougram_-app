# Capa de Models (ORM)

**Ubicación:** `backend/app/models/`

## Responsabilidades

Los Models son responsables de:
- ✅ Definición de entidades ORM (SQLAlchemy)
- ✅ Relaciones entre entidades
- ✅ Campos y tipos de datos
- ✅ Constraints de base de datos

## Restricciones

- ❌ **NO** contener queries SQL
- ❌ **NO** contener lógica de negocio
- ❌ **NO** manejar sesiones de base de datos
- ❌ **NO** hacer cálculos
- ✅ **SÍ** solo definición de estructura

## Estructura Base

Todos los Models heredan de `BaseModel`:

```python
from sqlalchemy import Column, Integer, String, Numeric, ForeignKey
from sqlalchemy.orm import relationship
from app.models.base import BaseModel

class MyModel(BaseModel):
    __tablename__ = "my_table"
    
    # Campos básicos
    name = Column(String, nullable=False)
    amount = Column(Numeric(15, 2), nullable=False)
    
    # Foreign keys
    organization_id = Column(Integer, ForeignKey("organizations.id"), nullable=False)
    
    # Soft delete
    deleted_at = Column(DateTime, nullable=True)
    deleted_by_id = Column(Integer, ForeignKey("users.id"), nullable=True)
    
    # Relationships
    organization = relationship("Organization", back_populates="my_models")
    deleted_by = relationship("User", foreign_keys=[deleted_by_id])
```

## Campos Estándar de BaseModel

- `id` - Primary key
- `created_at` - Timestamp de creación
- `updated_at` - Timestamp de actualización
- `deleted_at` - Timestamp de soft delete (opcional)
- `deleted_by_id` - Usuario que eliminó (opcional)

## Convenciones

- **Naming**: PascalCase para clases, snake_case para tablas
- **Tipos**: Usar `Numeric(15, 2)` para valores monetarios
- **Soft Delete**: Incluir `deleted_at` y `deleted_by_id` cuando aplique
- **Tenant Scoping**: Incluir `organization_id` para multi-tenant
