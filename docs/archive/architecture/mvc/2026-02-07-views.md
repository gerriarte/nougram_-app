# Capa de Views

**Ubicación:** `backend/app/views/`

## Responsabilidades

Las Views son responsables de:
- ✅ Transformar Models a Schemas (Pydantic)
- ✅ Agregar campos calculados dinámicamente
- ✅ Formatear datos para presentación
- ✅ Manejar paginación y listas

## Restricciones

- ❌ **NO** acceder a la base de datos
- ❌ **NO** contener lógica de negocio
- ❌ **NO** hacer queries
- ✅ **SÍ** solo transformación de datos

## Estructura Base

Todas las Views heredan de `BaseView`:

```python
from app.views.base import BaseView
from app.models.my_model import MyModel
from app.schemas.my_model import MyModelResponse

class MyView(BaseView[MyModel, MyModelResponse]):
    def __init__(self):
        super().__init__(MyModelResponse)
    
    def to_response(self, model: MyModel) -> MyModelResponse:
        if model is None:
            return None
        
        # Agregar campos calculados si es necesario
        model_dict = {
            "id": model.id,
            "name": model.name,
            # ... otros campos
            "calculated_field": self._calculate_field(model)
        }
        return MyModelResponse.model_validate(model_dict)
    
    def to_paginated_response(self, models, total, page, page_size):
        items = [self.to_response(m) for m in models]
        return MyModelListResponse(
            items=items,
            total=total,
            page=page,
            page_size=page_size
        )
```

## Métodos Disponibles de BaseView

- `to_response(model)` - Transformar un modelo a schema (debe implementarse)
- `to_list_response(models)` - Transformar lista de modelos
- `to_paginated_response(models, total, page, page_size)` - Transformar con paginación

## Campos Calculados

Las Views pueden agregar campos calculados usando Services de cálculo:

```python
from app.services.depreciation_service import DepreciationService

class EquipmentView(BaseView):
    def to_response(self, model):
        # Calcular progreso usando DepreciationService
        progress = DepreciationService.calculate_depreciation_progress(...)
        
        return EquipmentAmortizationResponse(
            # ... campos del modelo
            months_depreciated=progress["months_depreciated"],
            percentage_depreciated=progress["percentage_depreciated"]
        )
```
