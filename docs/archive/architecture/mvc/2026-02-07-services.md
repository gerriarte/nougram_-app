# Capa de Services

**Ubicación:** `backend/app/services/`

## Responsabilidades

Los Services son responsables de:
- ✅ Toda la lógica de negocio
- ✅ Validaciones de reglas de negocio
- ✅ Orquestación entre múltiples Repositories
- ✅ Cálculos y transformaciones de datos
- ✅ Invalidación de cache cuando es necesario

## Restricciones

- ❌ **NO** acceder directamente a la base de datos
- ❌ **NO** hacer queries SQLAlchemy directamente
- ❌ **NO** transformar Models a Schemas (usar Views)
- ✅ **SÍ** usar Repositories para todas las queries

## Estructura Base

```python
from app.repositories.factory import RepositoryFactory

class MyService:
    def __init__(self, db: AsyncSession, organization_id: int):
        self.db = db
        self.organization_id = organization_id
        self.my_repo = RepositoryFactory.create_my_repository(db, organization_id)
    
    async def list_items(self):
        # Usar repository, NO db.execute()
        items = await self.my_repo.get_all()
        # Aplicar lógica de negocio
        filtered = [item for item in items if self._validate_item(item)]
        return filtered, len(filtered)
```

## Tipos de Services

### 1. Service de Negocio
Contiene lógica de negocio y orquestación:
- `EquipmentService` - Gestión de equipos
- `ProjectService` - Gestión de proyectos
- `ServiceService` - Gestión de servicios

### 2. Service de Cálculo
Contiene solo lógica de cálculos (métodos estáticos):
- `DepreciationService` - Cálculos de depreciación
- `BlendedCostRateService` - Cálculos de BCR (futuro)
