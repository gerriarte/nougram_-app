# Manual Corto: Portal de Propuestas Nougram

## Objetivo
Compartir una propuesta comercial con el cliente mediante un enlace seguro, clave temporal y respuesta formal (aceptar, rechazar o solicitar revision).

## Flujo para el equipo comercial
1. Abre la cotizacion y entra a **Enviar Cotización**.
2. Verifica correo del cliente, asunto y mensaje.
3. Asegura que exista una propuesta guardada (puedes generar con IA o editar manualmente).
4. En **Acceso del cliente a propuesta** elige:
   - **Automática**: Nougram genera la clave temporal.
   - **Manual**: define tu propia clave (4 a 16 caracteres).
5. Haz clic en **Enviar Cotización**.
6. El cliente recibe:
   - correo con enlace al portal,
   - clave temporal,
   - vigencia del acceso.

## Vigencia y reenvío
- La propuesta queda disponible hasta **30 dias** por defecto.
- La empresa puede actualizar vencimiento y reenviar la misma propuesta.
- En cada reenvio se puede usar clave nueva (manual o autogenerada).

## Flujo para el cliente
1. Abre el enlace del portal.
2. Ingresa la clave temporal.
3. Revisa propuesta y cotizacion.
4. Responde una accion:
   - **Aceptar propuesta**
   - **Solicitar revision**
   - **Rechazar**
5. Puede agregar comentario opcional.

## Buenas prácticas
- Usar clave manual solo cuando el proceso comercial lo requiera.
- Evitar claves obvias (1234, empresa2026, etc.).
- Incluir contexto en el mensaje enviado para acelerar aprobacion.
- Si el cliente reporta “enlace expirado”, reenviar con nueva vigencia.

## Checklist de soporte rapido
- ¿Correo correcto del cliente?
- ¿Propuesta guardada antes de enviar?
- ¿Clave temporal enviada (manual o automática)?
- ¿Cliente revisó spam/promotions?
- ¿Vigencia aún activa?
